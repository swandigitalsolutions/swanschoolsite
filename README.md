# SwanSchool – demo school website

A fast, single-file demo website for a CBSE school (Nursery–Grade 12).

**Sections:** announcement ticker · hero · stats · about & principal's message · academics by stage (tabs) · facilities · a day at school · board results chart & toppers · events with filters · notice board · gallery with lightbox · testimonials · admissions steps, fees & key dates · enquiry form with validation · parent app preview · FAQ · contact · CBSE disclosure links.

**Performance:** one HTML file (~60 KB, ~15 KB gzipped), no frameworks, no image files (all graphics are inline SVG/CSS), one web font with `display=swap`, GPU-only animations, `prefers-reduced-motion` respected, light/dark themes.

**Run:** open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

All names, figures and fees are sample content.
